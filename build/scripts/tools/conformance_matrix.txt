# The functional conformance campaign's registry: the direct suites of this engine and the cases that
# must run and pass in them.
#
# It is a file rather than a paragraph because "all direct engine tests pass" is a claim about a *set*,
# and nothing else in this repository states what that set is. A suite that stops being generated
# prints nothing and disappears from "all".
#
# build/scripts/tools/run_conformance_campaign.py reads this file; nothing else does.
#
# Record types, one per line. Lines starting with '#' and blank lines are ignored.
#
#   suite <name> <always|optional>
#
#       A direct engine suite. `always` means the generator defines it unconditionally, so a tree
#       that does not build it is a failure rather than a smaller campaign; `optional` means it is
#       generated behind a switch, and the campaign runs it when the tree contains it and says that
#       it was not generated when it does not. The two are read against the generator in both
#       directions: a registered suite the generator does not define, and an unconditionally
#       generated suite the registry does not name, are both failures.
#
#   case <suite> <Fixture.Case>
#
#       A case that must exist, run and pass, so that "this case passes on this host" is a checked
#       claim rather than a sentence in a report. It is deliberately not a list of every case: the
#       suites already fail when one of theirs does.
