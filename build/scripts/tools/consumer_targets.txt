# The target registry: every target the Premake definitions generate, whether it reaches the engine, whether it is
# built, what it compiles, how its tests get their inputs, and which package profiles carry it.
#
# This file is the authority for the build set: the generator reads it and refuses a project it does not declare,
# and refuses the AFTERNIGHT_PRODUCT_ENGINE environment variable, because whether a target reaches the engine is
# stated here per target and no flag sets it for every source file at once. build/scripts/tools/consumer_targets.py
# holds the generated projects, both test runners, the source lists in isolated_sources.txt and the profiles in
# package_profiles.txt to it; check_installer_payload.py derives both packagers' allowlists from `ship`.
#
# A new target is declared here in the change that adds it.
#
# Record format - one per target, fields indented four spaces, a field continuing onto any line indented
# further:
#
#   target <project name>
#       workspace    main | tests | 3rdparty - the Premake workspace that defines it
#       kind         shared | static | console | windowed
#       output       <its binary's name when that is not the project name>
#       debug        <its Debug binary's name when that is not <output>_d>
#       class        none | engine - engine when its link closure holds the engine; the engine is its own
#       state        active (generated, built, tested) | opt-in (generated only when its build asks for it by name)
#       depends      <the registry targets whose libraries its link line names, or ->
#       sources      <the repository roots it compiles and includes from, beyond those of what it depends on>
#                    | @<the name of its explicit list in isolated_sources.txt>
#       fixture      for a test only - none (it builds no image input) | engine (it builds its inputs through the
#                    engine it tests) | neutral (the engine-neutral fixture layer) | adapter (the engine's fixture
#                    adapter, src/AfterNightTests/fixtures/engine)
#       runner       product - the numbered runners, run_tests.sh and run_tests.bat, expect it
#       ship         <the package profiles that carry it, comma-separated>
#       note         <free text>
#
# A field left out is `-`. Lines starting with '#' and blank lines are ignored.
