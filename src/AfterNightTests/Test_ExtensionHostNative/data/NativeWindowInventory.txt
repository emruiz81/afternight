# The widgets of the native process window's parameter panel, built from each schema of
# NativeWindowSchemas.json, a section a schema. A widget a line, in the order it was made,
# indented four spaces under the widget that holds it:
#   class | name | marks | state | tooltip | content | sizes | own layout | place
#
# marks       the widget's own properties that start with `an`, as name=value.
# state       `hidden` when it is hidden itself, `disabled` when it is not enabled.
# content     what the widget shows or holds: a label's text, a button's text and check,
#             an edit's text and placeholder, a spin box's range, step and value, a slider's,
#             a combo box's entries as text=value, a tab widget's tabs, a banner's message
#             and tone, a card's or a section's title.
# sizes       the minimum and maximum the widget was given, and its size policy.
# own layout  the class of the widget's layout, its margins and its spacing.
# place       where the layout of the widget's parent puts it: the path of item indexes
#             through nested layouts, a grid's row and column, and the alignment.
#
# Widgets Qt makes inside its own (named qt_...) are not listed, nor walked through but for
# a scroll area's viewport and a tab widget's pages. A collapsible section's content is sized
# to its fonts, so its size is not recorded.
#
# A section named for a schema and `focus` lists the widgets the Tab key reaches in the panel, in its
# order, as `class | name | id` - the id of the widget or of the row it sits in. That order is the
# order the widgets were made in.
