# The shape of the window every registered process opens, in the registry's order, extensions
# left out:
#   id | window class | framework class | layout | preview | button box | image selectors |
#   channel selector | menus | window | marks | key sequences
#
# framework class   the nearest of TopLevelProcessBaseControl, ImageProcessControl and
#                   ImageRTPreviewControl the window derives from.
# layout            of a window with a preview: `splitter: controls, preview` when the
#                   splitter named mainSplitter has two panes, the first holding the window's
#                   inputs and the second none; `row: controls, preview` when the window has
#                   no such splitter and its layout is a row whose first item holds the
#                   inputs and whose last holds none. The controls are a widget in a splitter
#                   and a layout in a row.
# preview           `checkbox, preview pane` when a checkbox named for the preview, checked,
#                   puts the preview view inside the splitter's second pane or the row's last
#                   item; `opens on` is added when the window opens with it checked.
# button box        the standard buttons of the window's button boxes, by name; `custom` for
#                   each button that is not a standard one.
# image selectors   how many combo boxes list the open images: the colour view the window
#                   is opened on or the grey view open beside it.
# channel selector  `yes` when a combo box lists the channels a process runs on.
# menus             the titles of the window's own menu bar.
# window            `resizable` or `fixed size`, then each window hint the window adds to or
#                   takes from a process window's.
# marks             what the person marks on a view for the process: an area, samples,
#                   stars, points. A window with a preview marks them on its preview view
#                   while it shows one, and the preview area every such window has is not
#                   listed; any other window marks them on the view it runs on.
# key sequences     every key sequence of the window's own actions and shortcuts, with its
#                   context and the action's text; `the keys of Undo` for the sequences the
#                   platform binds to a standard key. Keys a window reads in a key press are
#                   not listed: Escape closes every process window.
#
# A descriptor that opens no process window says so. No size is recorded: a pane's width
# follows the fonts of the host.
#
# ProcessCensus.EveryProcessStatesItsShape in Test_ProcessFramework compares every window with
# this record. An entry is edited by the change that means to move it - a process given a
# preview, a new shortcut, a retired process; the record is not written again whole. A field
# is `-` when empty; `\|` is a bar inside a text.
