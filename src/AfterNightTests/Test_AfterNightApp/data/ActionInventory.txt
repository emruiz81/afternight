# The actions and the menu bar of AfterNight 1.1's main window.
#
# [actions]: every action the window declares, in the order it declares them:
#   object name | text | tool tip | shortcut | shortcut context | icon | checkable or plain |
#   the menus of the menu bar that hold it, `;` between two
# The icon is the name of the application's icon resource the action shows. The actions are
# read with one image open that was never edited or maximized: Undo, Redo and Maximize View
# follow the active image.
#
# [menu bar]: the menu bar's tree, four spaces a level:
#   menu | object name | title      a menu and, under it, what it holds
#   action | object name            an action of [actions]
#   entry | text                    an entry the window adds that [actions] does not hold
#   separator
# A menu marked `varies` holds what a person did - the recent files, the favourite and the
# recent processes - and is held by its name alone; of the Extensions menu, which also lists
# what is installed, only the actions of [actions] are held. Neither counts among the menus
# that hold an action.
#
# ApplicationMenu.ActionInventoryMatchesTheRecord and .MenuBarTreeMatchesTheRecord in Test_AfterNightApp compares the running application with this record.
# An entry is edited by the change that means to move it - a renamed action, a new menu
# entry, a retired process; the record is not written again whole. A field is `-` when
# empty; `\t` is a tab and `\|` a bar inside a text.
