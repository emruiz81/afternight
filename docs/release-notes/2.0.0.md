# AfterNight 2.0.0

The notes of the 2.0.0 release, kept with the 2.0 line as it is built and published as the release's description.

## The interface

AfterNight 2.0 opens in a new main window, the **Observatory** shell: a rail of places on the left - Home, the
workspaces of open images, the Integration hub - with every process opening as a page beside its image instead of a
window of its own, a readout of the image beside it, and the command palette (`Ctrl+K`). It takes the place of the
main window of AfterNight 1.1, which this version no longer holds.

### Choosing a shell

The Observatory shell is the one shell this version holds, so there is nothing to choose: **Settings > Interface**
shows no Shell row while there is one shell to start. A shortcut or a script that names another shell - for instance
`--shell=classic` on the command line, or the environment variable `AFTERNIGHT_SHELL=classic` - names none this
version holds: it is passed over with a warning in the log, and AfterNight starts in the Observatory shell all the same.
`--shell=observatory` names the one it holds.

### Your settings from 1.1

Installing 2.0 over 1.1 keeps your settings, and AfterNight starts in the Observatory shell, as it does on a computer
it has never run on:

- your theme and contrast are kept as you chose them;
- your accent colour and surface tint are kept, and the Interface page shows them as the colour preset they make
  (Rose with Amethyst is **Nebula**, Blue with Neutral **Slate Blue**) or as **Custom** when they make none;
- the density, which 1.1 did not have, starts **Compact**;
- every other setting is as 1.1 left it.
