# AfterNight 2.0.0

The notes of the 2.0.0 release, kept with the 2.0 line as it is built and published as the release's description.

## The interface

AfterNight 2.0 opens in a new main window, the **Observatory** shell: a rail of places on the left - Home, the
workspaces of open images, the Integration hub - with every process opening as a page beside its image instead of a
window of its own, a readout of the image beside it, and the command palette (`Ctrl+K`). It takes the place of the
main window of AfterNight 1.1, which this version no longer holds. Every command, process and setting of 1.1 is still
there; the user guide's page **Coming from 1.1** says where each one went.

- **Places.** Home shows the images and sequences used last, the image to continue with and the quick actions, and a
  welcome on a new profile. Each workspace holds images docked as tabs, split or grouped by the layout icons in the top
  bar; a workspace can be added, renamed and moved to a window of its own. The Integration place lists the
  integration runs and starts a new one.
- **Tasks.** A process opens as a task: a page with the image - its preview, or the image itself - at the left and the
  process's controls in a column at the right, Apply, Reset and Close in its footer, and an item in the rail that shows
  a run's progress. Several tasks stay open side by side in the rail; one can float in a window of its own and be
  attached again. `Ctrl+Enter` applies, `Esc` closes a task that is not running, and F1 opens the user guide at the
  process's page.
- **The readout** follows the active image: its histogram, statistics, astrometry and facts, each card opening its
  window. A task shows the same of its preview, with the change against the original under each statistic.
- **The command palette** (`Ctrl+K`) finds every command, process, recent image and setting by name, the favourite
  processes first.
- **Projects** keep a set of images, their histories and their workspaces in a folder, and put them back when the
  project is opened again; the project switcher in the top bar shows the one that is open.
- **The menus** are the 1.1 menus, shown in a menu bar while Alt is pressed and under **All menus** in the top bar;
  **Settings > Interface** can keep the menu bar shown.
- **The look**: colour presets with a tint strength, a Compact and a Comfortable density, and Night (`Ctrl+Shift+N`),
  which draws the whole window in dim red for an observing night.
- **The keyboard**: every 1.1 shortcut is kept; F6 and Shift+F6 move between the rail, the centre and the column.

### Choosing a shell

The Observatory shell is the one shell this version holds, so there is nothing to choose: **Settings > Interface**
shows no Shell row while there is one shell to start. A shortcut or a script that names another shell - for instance
`--shell=classic` on the command line, or the environment variable `AFTERNIGHT_SHELL=classic` - names none this
version holds: it is passed over with a warning in the log, and AfterNight starts in the Observatory shell all the same.
`--shell=observatory` names the one it holds.

### Your settings from 1.1

Installing 2.0 over 1.1 keeps your settings, and AfterNight starts in the Observatory shell, as it does on a computer
it has never run on:

- your theme and contrast are kept as you chose them;
- your accent colour and surface tint are kept, and the Interface page shows them as the colour preset they make
  (Rose with Amethyst is **Nebula**, Blue with Neutral **Slate Blue**) or as **Custom** when they make none;
- the density, which 1.1 did not have, starts **Compact**;
- every other setting is as 1.1 left it.
