# AfterNight 2.0.0

The notes of the 2.0.0 release, kept with the 2.0 line as it is built and published as the release's description.

## The interface

AfterNight 2.0 opens in a new main window, the **Observatory** shell: a rail of places on the left - Home, the
workspaces of open images, the Integration hub - with every process opening as a page beside its image instead of a
window of its own, a readout of the image beside it, and the command palette (`Ctrl+K`). The main window of AfterNight
1.1 is the **Classic** shell, and this version holds it too.

### Choosing a shell

- **Settings > Interface > Shell** lists every shell this version holds. The one chosen is the one AfterNight starts
  in from then on; it takes effect when AfterNight starts again.
- **For one start**, name the shell on the command line: `AfterNight.exe --shell=classic` on Windows (in a shortcut's
  target, for instance), `./AfterNight-2.0.0-x86_64.AppImage --shell=classic` on Linux; `--shell=observatory` names
  the new one. The environment variable `AFTERNIGHT_SHELL=classic` does the same for every start of the session it
  is set in.
- The command line wins over the variable, and the variable over the setting. A name that is no shell's is passed over
  with a warning in the log, and AfterNight starts in the shell the next of them names - in the end the Observatory
  shell.

### Your settings from 1.1

Installing 2.0 over 1.1 keeps your settings, and AfterNight starts in the Observatory shell, as it does on a computer
it has never run on:

- your theme and contrast are kept as you chose them;
- your accent colour and surface tint are kept, and the Interface page shows them as the colour preset they make
  (Rose with Amethyst is **Nebula**, Blue with Neutral **Slate Blue**) or as **Custom** when they make none;
- the density, which 1.1 did not have, starts **Compact**;
- every other setting is as 1.1 left it.
